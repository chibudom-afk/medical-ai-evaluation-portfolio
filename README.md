**Projects**

**1. Medical Content Evaluation: Simple Renal Cyst vs Hydronephrosis**

**Objective:** Evaluate the accuracy of AI-generated explanations distinguishing simple renal cysts from hydronephrosis.

Evaluation criteria:

Medical accuracy

Anatomical correctness

Completeness

Clarity

Clinical relevance

Skills demonstrated: Medical knowledge, analytical reasoning, error identification, and written justification.

**2. AI Response Quality Assessment**

**Objective:** Assess AI-generated medical responses using structured evaluation criteria.

The assessment considers:

Factual correctness

Relevance to the question

Completeness of information

Clarity of explanation

Appropriate handling of uncertainty

**3. Rubric-Based Evaluation**

Objective: Apply consistent scoring criteria to assess the quality of AI-generated responses.

This project focuses on developing structured evaluation methods and providing evidence-based justifications for assigned scores.

**Evaluation Approach**

My evaluation process involves:

Understanding the question and expected response.

Reviewing the generated AI response.

Checking factual and medical accuracy.

Identifying missing or misleading information.

Comparing responses where applicable.

Assigning scores using defined evaluation criteria.

Providing clear explanations for evaluation decisions.
